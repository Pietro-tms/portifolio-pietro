# Portfólio — Pietro Strimber

Meu portfólio reúne projetos de desenvolvimento web, tecnologias que utilizo e formas de entrar em contato.

## Acesse

[Visitar o portfólio](https://pietro-strimber.vercel.app/)

## Projetos em destaque

- **Redação Clara:** aplicação para atividades de redação entre professores e alunos.
- [Casa do Hambúrguer](https://github.com/Pietro-tms/casa-do-hamburguer): projeto de gestão de pedidos para hamburgueria.
- [VacinaKids](https://github.com/Pietro-tms/vacinacao-infantil): interface para acompanhar a vacinação infantil.
- [Buscador de Receitas](https://github.com/Pietro-tms/Buscador-de-receitas): busca de receitas com dados da API TheMealDB.

## Tecnologias

- React e TypeScript
- Vite e Tailwind CSS

## Como executar

```bash
npm install
npm run dev
```
